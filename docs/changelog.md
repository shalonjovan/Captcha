# Changelog

See the project [CHANGELOG.md](https://github.com/shalonjovan/Captcha/blob/main/CHANGELOG.md)
for the full history.

## 1.0.0

- Nine challenge types: `text`, `noise`, `image`, `word`, `math`, `slider`,
  `click`, `pattern`, and `rotate`.
- Typed `Captcha` facade, `CaptchaConfig`, and `CaptchaResult`.
- Deterministic seeds, vectorised rendering, glyph caching, and new export
  formats.
- CLI with `list`, `info`, `generate`, and `gallery`.
- Custom generator registry and full MkDocs documentation.
- Src-layout packaging, tests, CI, and a PyPI publishing workflow.
